# OpenAI Workflow - Demo React App

Minimal Vite + React app to demonstrate a simple login/profile flow. Intended as a starting point to integrate OpenAI Workflows.

Quick start

1. cd into the folder

```bash
cd openai-workflow
npm install
npm run dev
```

App features

- Login / Create account (client-side, stored in localStorage)
- Profile page with name, surname, email, phone
- Lightweight routing with React Router

Next steps

- Wire this app to OpenAI Workflows: add a backend route or client-side calls to trigger workflows when users perform actions (e.g., submit profile).
